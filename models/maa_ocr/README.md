# Maa OCR models

These OCR assets come from [MaaCommonAssets](https://github.com/MaaXYZ/MaaCommonAssets)
and are used by MaaFramework when the `MAA 新版识别` backend is selected.

- `en_us`: battle numbers such as HP, ATK and PP.
- `zh_cn`: Chinese/Traditional-Chinese page text fallback.

Source path: `OCR/ppocr_v3/{en_us,zh_cn}`. MaaCommonAssets is distributed
under the MIT License; see the upstream repository for its license text and
model provenance.
