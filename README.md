# Shadowverse: Worlds Beyond 自动化脚本

一个用于《Shadowverse: Worlds Beyond》的自动化脚本工具，提供图形界面操作，支持多服务器配置、换牌策略选择、卡组管理和战斗自动化。

</div>

## 功能一览

### 核心功能

- **多服务器支持**：支持国际服和国服配置，并自动切换对应模板目录
- **换牌策略**：提供 3 费、4 费、5 费三个档次的换牌策略，用于优化起手手牌组合
- **战斗自动化**：自动执行回合结束、随从攻击、进化、超进化等操作
- **卡组管理**：支持保存、加载、分享和读取游戏官方卡组二维码；版本 5 使用 `card_id + count` 保存主卡组，并以唯一 `card_id` 保存无上限衍生物，兼容旧版卡组读取
- **本地卡牌库**：支持按职业、费用、卡包和稀有度筛选，并可手动检查官方清单后增量补充卡图与元数据
- **卡牌设置**：支持设置卡牌优先级、进化优先级、必留，以及出牌、攻击、进化、超进化等特殊效果
- **庆典模式**：支持庆典广场赛活动的自动化流程
- **空过功能**：可在战斗中直接结束回合，跳过其他操作
- **运行控制**：支持按运行时长或目标胜场停止，并在当前对战结算后安全关闭游戏

### 图形界面

- **设备连接检测**：支持检测设备连接状态并更新界面显示
- **状态栏显示**：实时显示当前状态、运行时间和对战次数
- **日志系统**：提供详细运行日志，便于排查问题
- **配置页面**：集中管理服务器、模式、运行参数和识别选项

## 面向普通玩家的安装与使用

### 安装步骤

1. 前往 [Release 页面](https://github.com/DaydreamStarRiver/Svb_Byd_Deck_Auto/releases) 下载最新版本安装包
2. 将安装包解压到任意目录
3. 运行 `Shadowverse_Auto.exe` 启动程序

### 使用步骤

1. **配置设置**
   - 选择服务器（国际服/国服）
   - 如国际服画面存在偏暗问题，可开启深色识别
   - 根据活动需要选择是否启用庆典模式
   - 根据需要选择是否启用空过功能

2. **连接设备**
   - 启动模拟器并进入游戏
   - 点击“连接设备”按钮，确认设备连接状态正常

3. **卡组选择**
   - 在“卡组选择”页面选择与游戏中相同的卡组
   - 点击“保存卡组”保存当前选择

4. **卡牌设置**
   - 在“卡牌设置”页面设置卡牌出牌优先级、进化优先级和必留规则
   - 如需配置二选一、指定目标等特殊交互，点击右侧“特殊效果...”进入二级编辑器
   - 点击“保存设置”保存配置

5. **参数设置**
   - 调整拖拽速度，通常保持默认即可
   - 设置自动重启时间，建议 3-10 分钟
   - 根据需要配置运行终止条件

6. **开始运行**
   - 确认模拟器分辨率、场地和卡组均已正确设置
   - 点击“开始运行”启动脚本

## 面向开发者的安装与使用

### 开发环境搭建

1. 克隆项目仓库：

   ```powershell
   git clone https://github.com/DaydreamStarRiver/Svb_Byd_Deck_Auto.git
   cd Svb_Byd_Deck_Auto
   ```

2. 创建并激活虚拟环境：

   ```powershell
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. 安装依赖：

   ```powershell
   pip install -r requirements-py311.lock
   ```

4. 运行图形界面：

   ```powershell
   python main_ui.py
   ```

5. 运行命令行版本：

   ```powershell
   python main.py
   ```

### 项目结构

```text
Svb_Byd_Deck_Auto/
├── main.py                    # CLI 入口
├── main_ui.py                 # GUI 入口
├── src/                       # 核心源码目录
│   ├── app/                   # 应用启动与组合入口
│   ├── config/                # 配置管理、路径与策略配置
│   ├── core/                  # 日志、运行控制等核心基础能力
│   ├── device/                # 设备连接与设备状态管理
│   ├── game/                  # 游戏识别、战斗逻辑与策略执行
│   ├── ui/                    # PyQt 图形界面
│   └── utils/                 # OCR、图像处理、资源路径等工具函数
├── templates/                 # 国服模板图片
├── templates_global/          # 国际服模板图片
├── models/                    # OCR 和 MNIST 模型
├── docs/                      # 用户与开发文档
├── requirements-py311.lock    # Python 依赖锁定文件
└── requirements-build.in      # 构建依赖说明
```

### 配置说明

- `config.json`：存储服务器、模式选项、卡牌优先级、进化优先级和特殊效果配置
- `card_cost/`：卡牌费用识别模板目录，运行时按需生成或迁移
- `saved_decks/`：保存的卡组配置目录，运行时按需生成
- `consent.txt`：免责声明同意状态文件，仅用于本地运行状态记录

### 手动更新卡牌库

GUI 的“卡组中心 → 卡组构筑 → 检查官方更新”只在用户点击时联网，并会先显示差异预览。开发者也可使用同一安全更新内核：

```powershell
python scripts/crawl_sv_card_set.py --dry-run
python scripts/crawl_sv_card_set.py --card-set 10010
python scripts/crawl_sv_card_set.py --dict-only
```

更新过程采用低频串行请求、限流退避、图片解码校验和暂存安装；任一资源失败时不会留下半套卡牌库。

### 打包与发布

1. 安装运行与构建依赖：

   ```powershell
   .venv\Scripts\python.exe -m pip install -r requirements-py311.lock
   .venv\Scripts\python.exe -m pip install -r requirements-build.in
   ```

2. 执行打包脚本；脚本会使用项目虚拟环境并在完成后复制外部资源目录。

   ```powershell
   .\build.ps1
   ```

3. 打包完成后，检查产物是否包含模型文件、模板目录、图标和必要的运行时 DLL。

## 已知问题

1. **国际服深色模式**：MuMu 模拟器运行国际服时可能出现画面过暗问题，导致模板识别失败，可尝试开启深色识别选项
2. **画面分辨率**：当前仅支持 1280x720 分辨率，请确保模拟器分辨率设置正确
3. **场地选择**：建议使用黑色背景场地，避免使用简易场地，否则识别错误率可能上升
4. **MNIST 运行时**：HP 数字兜底识别已改用 OpenCV DNN 读取 `models/mnist_adv.onnx`，不再依赖 ONNX Runtime 原生 DLL

## 注意事项

1. **使用环境**
   - 请使用 1280x720 分辨率
   - 建议使用黑色背景场地，不建议使用简易场地
   - 画面设置可参考压缩包内的“对战画质1”和“对战画质2”

2. **卡组同步**
   - 脚本卡组选择需要和游戏内卡组保持一致
   - 保存卡组时，请确保游戏内使用的卡组、衍生物和脚本配置一致

3. **服务器选择**
   - 支持国际服和国服
   - 深色识别仅建议国际服画面偏暗时开启

4. **使用规范**
   - 本工具仅供个人娱乐和技术交流使用
   - 请遵守游戏相关规定，合理使用
   - 不要过度依赖脚本，避免影响游戏体验

5. **风险提示**
   - 使用脚本可能存在被游戏官方检测的风险
   - 作者不承担因使用本工具导致的任何游戏账号问题
